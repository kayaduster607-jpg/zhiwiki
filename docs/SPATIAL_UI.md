# 3D 知识空间

> 第四轮历史实现。2026-09-11 首页已切换为 [知识档案馆](ARCHIVE_UI.md)，不再加载下述球体脚本。

首页采用原生 WebGL 粒子球、三条空间轨道和可点击的来源卡片。视觉参考 [ThreeUI Orbital Sphere](https://threeui.com/three-js/structure-flow/orbital-sphere)，保留知证的深墨蓝与薄荷青。几何、着色器和交互代码为本项目编写，没有引入 Three.js、购买组件代码、CDN、字体或模型资产。

## 展示与事实

球体和轨道负责空间氛围；资料卡片及 Wiki 卡片来自现有 API。卡片间的曲线只来自 Wiki 的 `source_ids` 与当前原文 `chunk_ids` 的对应关系，重复引用合并，归属不唯一的片段不生成连线。草稿、失效页和旧版原文不会作为有效节点。

数据模型最多选取 8 份原文与 4 页有效已发布 Wiki，优先覆盖引用关系，再补近期资料。立体主场景聚焦其中最多 **4 份原文与 2 页 Wiki**，平面图沿用最多 8+4 的展示。页脚明确显示展示数和知识总数，其余内容从资料与 Wiki 列表访问。当前 16 份原文、4 页演示 Wiki 时，立体场景显示 `6/20`。

节点的位置、球面距离、轨道、颜色亮度不表示语义相似度、检索排名或 Agent 执行进度。已有来源关系也不等于 GraphRAG 的实体社区检索。打开卡片仍进入原有详情、版本与引用流程。

## 交互与降级

| 操作或状态 | 行为 |
|---|---|
| 拖动球体 | 水平旋转，垂直俯仰有边界；手机保留页面竖向滚动 |
| 画布获得键盘焦点 | 方向键转动、Home 复位；Tab 可到来源按钮 |
| 悬停或聚焦节点 | 暂停自动运动，突出该节点的实际引用关系 |
| 暂停旋转 / 复位视角 | 分别控制场景运动和观察角度 |
| 平面视图 | 切换到已有 SVG 来源图，保持详情入口 |
| 全局动效关闭 | 停止自动循环，保留手动拖动与来源访问 |
| WebGL 初始化、绘制失败或上下文丢失 | 释放渲染资源并显示平面图；上下文恢复时重新建立资源 |

按钮保留完整标题作为可访问名称和提示，较长可见标题截短不改变原始资料名。初始动效遵从系统 `prefers-reduced-motion`，用户可通过现有全局开关调整；这与 [MDN 的减少动态效果媒体查询](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion) 一致。上下文丢失/恢复按浏览器事件处理，参考 [MDN webglcontextlost](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/webglcontextlost_event)。

## 渲染与维护

| 模块 | 职责 |
|---|---|
| `spatial-model.js` | 选择有效数据、建立真实引用边、纯函数透视投影；可在 Node 独立测试 |
| `orb-renderer.js` | WebGL 1 几何、着色器、缓冲区、绘制与释放；不自行开启动画循环 |
| `spatial-scene.js` | DOM 卡片和 SVG 引用层、相机交互、单一动画循环、可见性和降级 |
| `spatial.css` | 首页布局、空间层次、焦点与响应式样式 |
| `workspace.js` / `app.js` / `motion.js` | 将既有数据、导航可见性及全局动效状态传给展示层 |

渲染器一次建立 2,834 个程序化点、3 条轨道以及二十面体核心的几何缓冲。卡片、引用路径和 GPU 几何使用一致的 Y→X 旋转、距离 6 的相机和 45° 垂直视野。自动旋转采用小幅往复，保证节点可读；完整旋转由用户主动拖动。

像素比最多 1.5，画布缓冲最多 150 万像素。循环中不逐帧读取卡片布局、不重复创建几何；视图离开首页、场景离开可见区域、页面隐藏、零尺寸、暂停或关闭动效时停止持续帧循环。资源创建失败同样执行释放。限制渲染分辨率与主动释放对象参考 [MDN WebGL best practices](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices)。这些是实现约束，尚未测量跨设备 FPS、功耗或长时间运行表现。

该模块不请求新接口，不改数据库、检索和模型配置。后续如增加几何或交互，优先保持渲染器与状态控制器分离，避免业务逻辑进入着色器或逐帧循环。
